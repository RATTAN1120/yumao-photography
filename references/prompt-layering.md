# 自包含分层提示词协议

本协议用于没有可靠历史上下文的生图模型。分层标题只服务于人类整理，不能代替可见画面描述；每层必须写成模型可直接执行的自然语言。

## 六层结构

1. **固定层**：人物成年状态、身份特征、发型、服装轮廓、配色、眼羽材质与工艺家族。
2. **结构层**：眼羽羽片数量、搭接顺序、遮挡范围、布局锚点、身体关节和物体接触关系。
3. **变化层**：本次姿势、表情、镜位、光线或场景变化。
4. **修复层**：只描述当前失败局部的改动，并明确“其余固定层保持不变”。
5. **限制层**：当前画面最高风险的错误，避免把已选材质、形态或布局笼统禁掉。
6. **验收层**：生成后按固定项、结构项、变化项和修复项分别检查；不能用整体美观抵消局部结构失败。

## 使用边界

- 区分本文的信息分层、画面中眼羽在面部前方的遮挡层次，以及编辑软件真实图层。前两者不证明工具执行了第三者；佩戴构造见 [统一构造](form-family.md)，不在此另建模板。
- 已获图片编辑授权且工具支持时，若单次生成持续把饰物与眼部融合，可考虑保留人物底图、局部添加独立眼羽的分步方案；局部范围须包含覆盖、固定与必要投影，并重新检查表面假眼、身份和服装保持。纯提示词请求不自动启动生图，分步处理也不承诺必然成功。

- 不假设模型理解“锁定图层”“保持不变”等抽象术语；必须同时写出具体对象、位置、方向、连接和接触关系。
- 分层协议不是越长越好。删除重复、冲突和无法观察的内部原因，保留能改变画面的关系。
- 修复任务不得把换形态、换布局或换材质当作原错误已修复；这些只能标为探索方案。
- 是否提升效果需用同模型、相近参数和同一参考图做对照测试，记录服装保留率、眼羽结构通过率、肢体正确率和局部修复率。未经对照，不宣称协议已被模型验证。
