# 侧源扩展与旧编号兼容

默认始终是中央连接 `centered`。侧源是明确选择后的扩展，不是更高级或更新的默认。

旧01–10保留识别，避免已有请求失效；它们是历史预设，不是十个正交的布局维度。不得偷偷重编号，也不能承诺全部与四形态自由组合。路径左右以人物自身为准，需要时补充画面侧。

| 旧编号 | 保留的含义 | 形态处理 |
| --- | --- | --- |
| 01 | 耳上或太阳穴侧源，近水平跨双眼，对侧渐细 | 收束最直接；其他形态须另说明外端路径 |
| 02 | 较低耳侧起始，斜向上跨双眼，结束于对侧眉上附近 | 收束或开羽；检查下方眼区覆盖 |
| 03 | 耳上起始，跨双眼后沿对侧颧骨外缘下弯 | 是侧源＋垂羽预设，不是任意四形态容器 |
| 04 | 耳侧起始，跨双眼后向对侧上方展开 | 是侧源＋开羽预设 |
| 05 | 同一起点分上下两股，中间仍由完整羽片搭接填满 | 分流组织方式；常用于开羽或垂羽，不能围眼孔 |
| 06 | 同一起点主流跨双眼，短辅流回折耳后 | 是主辅两路＋环覆预设 |
| 07 | 一侧主要连接，对侧较小辅助固定，视觉重心偏置 | 是固定方式，可配收束或环覆；按实际路径判断 |
| 08 | 冠侧或发际上方起始，沿额侧下降后覆盖双眼 | 是起点与入眼路径，可配收束或垂羽，勿变刘海 |
| 09 | 耳后起始，绕太阳穴向前覆盖双眼 | 本身具有包覆路径，优先环覆；不能只贴侧片 |
| 10 | 旧材料／元素探索入口，没有独有空间路径 | 不再当独立布局；保留输入兼容，另明确实际起点与路径 |

未提供10的实际路径时：保留旧“侧源探索”意图，采用01的覆盖路径作为明示假设，再落实用户形态；标明“旧10：材料探索；实际路径01＋所选形态”，不伪称用户明确选了01。只要求元素材质而未提旧10时，仍用中央连接，不自动侧源。

## 遇到冲突

- “布局03＋收束”同时锁定相反外端路径：指出冲突，询问保留下垂路径还是改收束，不自行删除明确要求。
- “固定布局03，四形态各一张”：不能声称原布局全部保持；提出保留同一侧部连接工艺、开放外端路径的方案，明确需要改变的范围。仅当用户已授权重构布局时执行取舍。
- “同款四形态、未指定布局”：直接中央连接四形态，无需询问或从旧编号中挑选。
- 空间描述比编号更具体时，以明确描述为准，指出与旧编号的差异，不发明新编号。

## 实际结构

侧部装饰起点清楚可辨，连接发饰、头带或隐藏承托；多羽片连续进入双眼与鼻梁。实体不从皮肤生长，元素有可读凝聚来源。近远侧遵循头部曲面；耳后起点可由侧面连续关系辨认，不要求正面看穿头发和头部。

侧源不强制中央独立扣件；用户明确同时保留中央饰品时可设计组合，不让两个中心破坏覆盖。材料与无眼睛意象沿用[唯一构造](form-family.md)。示意见[参考页](structure-atlas.html)，不将预设图视为已验证成图。
