# 眼形问题：证据诊断与验证

先读取 [案例对照](case-evidence.md)。检查全图和原始比例的整个眼羽及配饰局部；等比放大不恢复缺失细节。重复图片去重，背景海报眼睛不计入主角。实眼不确定时只报告可见的眼形，不臆测瞳孔或模型原因。以下分类只决定修复方式：真实眼睛与任何假眼意象均不合格，不能用“没有真实露眼”通过验收；单侧、非闭合、不在真实眼位的眼睛暗示同样失败。

| 类别 | 可观察证据 | 对应修改 |
| --- | --- | --- |
| 实际露眼 | 明确眼睑、睫毛、眼白或瞳孔 | 恢复根部遮挡与隐藏承托，保留 Form |
| 接缝假眼 | 相对边缘围成尖端长缝/杏仁形，可能只有一侧 | 改局部搭接，完整羽面跨过闭合区域，不能仅增加不透光 |
| 单片/折脊假眼 | 单枚梭形裁片、卷边或折脊与暗轴组合成眼形，即使没有露眼或长接缝 | 按统一构造重组可见轮廓、线脊走向和局部投影，不只藏接缝末端 |
| 可见框/填充 | 深色或金属边围浅色眼状填充 | 移除眼形框或填充，承托完全隐藏；不必取消所有饰件 |
| 色差假眼 | 成对高对比梭形斑块 | 改色块位置与边界；保留整体服饰配色 |
| 眼睛符号或暗示 | 羽片、接缝、阴影、纹样或饰件呈闭眼线、眼状斑纹、抽象眼符号等，不要求闭合或成对 | 重组对应羽片、边界或饰件纹样，保留连续覆盖与所选结构锚点可见 |
| 普通层次 | 短小分散阴影，不呈现任何可读眼睛意象 | 保留，不因“有缝”就压平羽片 |

这些分类可以同时出现。先看边界围出的形状，再判断颜色和饰件，不把所有失败简化成“中央有饰件”或“羽毛不够多”。认可图也有中央汇合；禁止其存在是无证据的过度约束。

## 修复规则

常规正向只使用 [form-family.md](form-family.md) 共同覆盖、目标路径和服饰适配。诊断后替换有问题的局部构造，不在旧模板后不断拼接补丁。眼区可使用相近色调降低眼状明暗对比，但不能把“同色”当作必然有效或所有材质的硬要求。保留所选布局的可辨结构锚点：centered 为中央连接，布局01–10为对应侧部锚点；修复其造型与接缝，不以删除锚点或强加中央扣件解决眼形；不得组织成眼形边框。隐藏背衬只修实眼，不修表面假眼。

审核尺寸、Form 和装饰不能互相代偿：不通过缩掉外羽/加厚面罩解决假眼；不因禁止眼形而禁所有曲线、对称和正常羽轴。开羽与环覆的变化不破坏中央覆盖，但没有证据证明必须严格从某个太阳穴坐标才可转折。

## 原始提示词与成图对照

先核对实际发送的正向、负向、参数与随附图片，不默认另一个生成器能读取技能、历史或本地文件。按 [独立交付](prompt-handoff.md) 区分传递遗漏、描述缺口/冲突及明确要求未执行；多项可并存。看到假眼不代表知道它是透出的真实眼部，也不能证明缺少记忆、某语言或某种材料就是成因。

本次纱衣四形态案例中，原文已经含不透视覆盖与无眼睛意象要求，而所提供的局部图仍见眼状暗缝/边缘。因此不能仅补禁词或声称规则未传递；需对照织物羽面、折脊、层叠与照明的具体表达。截图与每套原文未确认逐一对应时，不强行配对；局部截图也不能证明全身姿势或构图是否合格。此证据不证明欧根纱必然失败，不构成新版修复成功样本。

## 反复失败的处理

在当前对话核对实际使用的完整提示词版本、模型/参数、是否接收参考图和是否同一输出；仅用户明确要求保存时才将完整提示词落盘。核对这些条件（信息缺失则标记未知，不要求先补齐才分析可见问题）。旧六套的成图不能证明后续补丁有效或无效；不同角色、颜色、视角不是控制实验。

用户要技能修复时，审查所有规则来源和实际模板传播，不转交单张修图任务。新成图未验证时只能报告规则一致性改善。只有用户明确要求出图/编辑才进行参考约束或中央局部重建；每次仍需看图验收，不承诺纯文本零假眼。
