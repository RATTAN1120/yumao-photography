# 眼形问题诊断

按[交付验收](prompt-handoff.md)查看全图与等比局部；需要历史证据才读[案例](case-evidence.md)。不从暗缝臆测瞳孔，不把文件名当判定。

| 可观察问题 | 对应修改方向 |
| --- | --- |
| 真实眼睑、睫毛、眼白或瞳孔露出 | 恢复当前视角的连续覆盖；仅改根部，不无故缩外羽 |
| 相向羽缘或缝形成眼状轮廓 | 重组局部搭接，让完整羽面打断该边界；加厚背衬不能修表面假眼 |
| 单片折脊、羽轴和投影组合成眼形 | 调整该处轮廓与受光，不仅藏缝末端 |
| 金属框、色块或饰品呈眼形 | 修改对应纹样和边界，保留连接职责、材料及原设计特色 |
| 正常羽轴或短分散阴影 | 保留，不泛禁曲线、对称、中央饰品或所有接缝 |

真实露眼与表面眼形都不合格；单侧、非闭合和非眼位的眼睛意象也检查，但必须能指出视觉依据。分辨率不足标无法确认，不按主观联想扩大禁令。中央连接缺失与假眼是两个独立问题。

修复仍遵从[唯一构造](form-family.md)，不以换形态、删珠宝或换成黑带逃避。几何策略未做新成图验证前只称候选修订。两次同类失败按交付文件的停止与诊断规则处理。
