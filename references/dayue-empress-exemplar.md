## 值得复用的设计关系

| 设计层 | 本例的具体处理 | 迁移方法 |
| --- | --- | --- |
| 人物与服装 | 成年真人；黑色高髻、金色镂空冠与红垂珠；红缎抹胸、宝蓝金纹腰封、红金长衣片、金色首饰 | 先展开选定参考的剪裁、连接、发型与配饰，不只写角色名；不把本次参考说成已核实的官方完整设定 |
| 眼羽联动 | 蓝、红、金多枚薄金属羽片；服装蓝色与红色进入羽面，金纹语言进入连接和分段羽轴 | 服饰主辅色、线条与工艺一起转译，非天然材料仍保留独立羽片、轴向、层叠和渐细羽端 |
| 下身补全 | 浅肤色低光泽丝袜、低对比金色卷草花纹、红色金纹鞋履 | 此项来自当次用户补全授权；纹样沿腿部走向延续服饰语言，不在未授权任务中自动新增丝袜或改鞋 |
| 材质分工 | 缎面定向柔光、金属局部反光、丝袜低光泽纱感、皮肤自然纹理 | 同一光源下区分材料，不把全身写成同样发亮的塑料表面 |
| 场景与摄影 | 宫苑软榻、朱柱、木格窗、远处亭台；侧窗光与面部反射补光 | 同一世界观中改变机位、动作与光线，保持衣服和眼羽方案；全身容纳头冠与双鞋 |
| 姿态表达 | 腹部、骨盆、大腿贴榻；双前臂承托；双膝分离、双小腿高低错开、双踝不交叉 | 先落实支撑和关节连接，再让长衣片铺向身体两侧，不能用飘布掩盖连接错误 |

## 提示词写法的最小示例

### 设计重点与遮挡表达复核

本轮对照E01、E04全图与用户引用的粉色丝缎眼羽段：E01可见长短羽片形成的横向节奏及蓝色主羽、红色外羽、金色连接的分工；E04可见侧部展开与横跨眼区羽流形成的轮廓变化。两图提供“具体造型在整体画面中仍可辨”的参考，不证明其材质或措辞是成功原因。丝缎段已有材料、暗缝、卷边和覆盖描述，但轮廓节奏与连接特色较通用，摄影呈现没有围绕某项设计特色展开；这属于文本表达不足。未提供该段对应成图，不能据此判定实际成图平淡，也不能认定丝缎材质本身不适合亮眼设计。

据此将设计辨识度与遮挡合格分开检查，并用面前佩戴、固定和光照关系解释空间层次。此次为规则与文本修改，未做同模型同条件的新成图对照；不能宣称“图层表达”已经提升成功率。

以下是依据历史方案整理的教学片段，不是历史原稿或新的完整生图提示词，也未经过新成图验证。完整交付仍按主文件与 [统一构造](form-family.md) 展开所选布局、形态、尺度和固定方式。

**服饰—眼羽联动片段：**

宝蓝金纹腰封的蓝色进入主要金属羽面，红缎衣片的红色用于少量外侧辅羽，金色纹线转成分段浅浮雕羽轴。完整羽面错位跨压鼻梁及眼区接缝，金线在眼区中段错开收尾，避免相向边界围成眼形；保持多羽片层叠和所选结构锚点，不靠加厚底板代替表面调整。

**姿态—服装—构图片段：**

人物腹部、骨盆与双侧大腿贴合软榻，双前臂承托上身；双膝留有间距，两条小腿各自向上屈起且高度略有差异，双踝不交叉，每只鞋沿对应脚掌方向贴合。红金长衣片铺在身体两侧，不缠膝踝。相机保持足够距离，完整纳入头冠、躯干和双鞋。

交付次序采用：生成意图与成年主体 → 参考各自用途 → 服装及已授权补全 → 具体眼羽构造 → 单一瞬间的动作与支撑 → 场景、镜头及光线 → 当前风险负面词 → 参数。可按画面重点调整次序，不照抄历史冗长禁词。每套标题、正向、负向和建议参数放在同一个可复制单元内；审核说明在外。

## 复用时必须保留的边界

- 面容图只负责身份与妆容，服装参考负责服装，姿态图负责动作；未向生成器传图时，把可描述特征写全，不使用“沿用原图”作为替代。
- 历史修订里的“保留原布局、原层叠数量”只适用于参考同时提供的局部修复。独立新提示词必须展开实际连接位置、羽流路径及形态，不猜测图中隐藏的锚点或精确数量。
- 原提示词称“软鞋”，保存成图可见明显鞋跟；鞋型需按本轮选定参考或授权确定，不能把原文与成图视作逐字一致。
- [F8早期假眼案例](case-evidence.md) 继续有效。保留蓝红金设计不等于保留眼形边界；仍逐项检查真实眼部遮蔽、整个眼羽无眼睛意象、形态、尺度及锚点。10号图原有姿态认可不自动构成眼羽全项通过。
- 既有局部修复只改失败关系，不以换材质、改服装或换形态冒充修复。新题材则重新从其服装推导，避免把本例配色、珠宝与姿势变成固定模板。
