# 独立交付与验收

## 编写

先确定锁定项、参考用途、中央或侧源构造、形态、材料、设计特色、视角与画面边界。构造只读[唯一规范](form-family.md)，不把内部检查表抄进提示词。先删除冲突，再压缩重复；眼羽为核心时提前描述，不埋在冗长环境与服装段后。

默认中文，每套首行名称、正向、负向、建议参数放在同一独立可复制块，审核说明在外。首行统一为“01｜角色或主题 · 方案名称”，不加“标题：”或“序号：”前缀。单套也编号，多套依次递增，修订保留对应序号。宿主有专用写作块时遵从宿主，否则用无语言标记代码块。不得默认保存完整提示词文件。

- **正向**：以“请生成一张……”说明成年主体、画幅和渲染；展开眼羽特色、连接与覆盖、形态和材料，再写人物服装、动作、环境、镜头与光线。顺序随编辑任务调整。不能只说编号、“沿用原方案”“严格一致”。
- **负向**：核心为真实露眼、整件饰物的眼睛意象、眼孔/外露眼框、单根巨羽或整块面罩退化、皮肤生翼；另补当前最高风险。中央构造检查中央连接件，侧源检查实际连接，不机械强制两者。不得误禁已选材料、形态、曲线、对称或裁切。
- **参数**：画幅、平台自动尺寸、单一焦段或明确手机摄影方式、景别、形态、实际布局说明、系列固定与变化项。不虚构平台专用负面字段，不自动加8K等质量标签。

正向单独阅读也须确定画面；负向不能补建缺失结构。全身与七分身不能同时锁定；脚部要求随景别。锁定裁切时不擅自扩图。

## 中文表达

适用于所有形态、布局、材质及人物、服装、动作、摄影描述。使用符合中文习惯的连贯句子，准确说明画面，不把提示词写成抽象说明或零件清单。语言润色不得改变设计条件。

- **对象和关系写清楚。** 先交代是什么、位于哪里，再说明怎样连接、排列或运动，最后补必要限制与工艺。按内容自然成段，不强制每句套同一顺序。少用只有评价而无具体内容的“高级、协调、受控、自然衔接”；写出实际部件与关系。
- **同一部件使用同一名称。** 有装饰作用的中央衔接部件称“中央连接件”，保留其装饰设计职责；“羽组”指整体，“羽片”指组成部分，“承托结构”指背部支撑。侧部连接件仅用于实际侧源方案。元素结构按实际凝聚与衔接关系描述，不为统一术语凭空添加实体零件。
- **参照明确。** 区分佩戴者左右、画面左右、面部中线及近远侧；“连接件”是物件，不是对称轴。需要描述对称时写对应中线及哪些部位对称；结构对称不等于斜侧视的投影相同。
- **动词和量词准确。** 按实际关系使用“衔接、搭接、叠压、覆盖、展开、弯垂、向后延伸”等；角度说“大或小”，位置说“高或低”。无法确认的尺寸、数量、工艺不因追求具体而编造。
- **否定范围恰当。** “不得出现透出真实眼部的孔洞或缝隙”不等于禁止所有搭接缝；“羽面连续覆盖”不等于必须一体成型；不得将无眼睛意象缩窄成只禁止两个眼框。
- **抽象依据转为实际描写。** 设计时可以考虑“服饰联动”，交付时应写所采用的配色、线条或工艺，以及它们位于哪个部件。不能只把抽象词换成另一种抽象说法，也不凭空补出制作方法。

以下是条件性语言示例，不是全局造型要求，不整体拼入提示词：

| 原表达 | 按实际设计改写 |
| --- | --- |
| 上下张角较低，横向顺叠 | 上下展开角较小，羽片向两侧横向依次叠压 |
| 以中央连接饰品为对称轴 | 以中央连接件的中线为对称轴（仅在设计要求对称时使用） |
| 形成受控的不规则对称 | 左右整体均衡，右侧外羽略长（仅在该差异已确定时使用；要求镜像时不加差异） |
| 从服装工艺中推导连接 | 中央连接件采用与衣领一致的缎带编结工艺（仅在已选用此工艺时使用） |
| 垂羽自然衔接 | 外侧羽片依次搭接，沿脸侧连续向下弯垂 |
| 环覆具有空间包覆感 | 羽组沿太阳穴向头部侧后方延伸（对应当前环覆路径） |

交付前通读：每句话能否明确回答谁在何处、与什么发生何种关系；术语、参照和指代是否一致；限制是否误伤正常结构；是否因润色增删了用户要求。只改语言缺陷，不把某一形态的连接位置、对称性或羽片方向推广到其他方案。表达准确不等于已验证出图效果。

## 参考交接

身份、服装、动作、眼羽结构参考分别说明职责。单图用“所附参考图”，多图确有必要时逐一说明并确认接收方可用。读取技能图片不等于生成器收到图片，本地路径也不等于上传。

HTML/SVG为可维护参考，PNG为兼容副本。向生成器提供与目标有关的单项图，不把整页标注、失败对照或十布局拼图当目标画面。辅助文字、眼区定位线、示意配色不属于成品。纯文本需展开结构，但不承诺同脸或同款逐像素一致。

## 分项检查

| 对象 | 所需证据 |
| --- | --- |
| 真眼遮挡 | 当前机位下双眼、眼睑和睫毛不可见，不靠暗部或模糊猜测 |
| 表面眼睛意象 | 整件饰物含中央/侧部饰件无可读眼形；指出具体失败边界，普通羽轴不自动失败 |
| 构造与形态 | 多羽片、连续搭接、当前连接职责和所选羽流成立；近远侧跟随头部体积 |
| 设计与材料 | 轮廓、节奏、服饰工艺关系可辨；材料受光与遮挡兼容 |
| 保留范围 | 人物、服装、配饰、姿势、裁切符合锁定范围，不只颜色相似 |
| 人体与场景 | 肩—肘—腕、髋—膝—踝—足归属可追踪；支撑、接触、鞋物数量与透视相容 |

全图与必要局部一起看，细节不足标“无法确认”。设计协调不抵消硬性失败，硬性通过不代表设计有特色。文字执行度与设计评价分开。

## 修复与停止

确定保留项和失败项，替换导致问题的描述，不无故换形态、缩外延、换材质、删装饰或改服装。用户要完整稿时交付自包含稿，不只给补丁。

连续两次同类失败后核对实际输入、版本、参考接收、空间关系和生成方式；未知标未知，不阻止已有证据分析。分清规则冲突、传递缺口、模型未执行、工具限制，不推断模型内部因果。没有新成图不能称视觉修复成功，局部重绘不证明整图生成成功。

## 可迁移性验收

先查包内相对链接和资源，再在无历史上下文条件下检查真实任务：默认中央连接、四形态差异、侧源冲突、元素不强制底板、局部修复保留范围。检查实际空间与设计关系，不只匹配关键词。记录对象、条件和失败项；一个Agent通过不代表所有Agent或生图平台通过。实际出图另获明确授权后验证。
