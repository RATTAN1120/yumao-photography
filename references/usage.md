# yumao摄影用法

默认输出中文标题、中文正向与负向提示词、建议参数；用户明确指定其他语言时遵从。语言选择用于清楚表达结构，不代表已验证中文出图效果优于英文。正负段为普通文本，不用代码块。每条正向第一句明确写“请生成一张……”并完整展开画面，不依赖技能名、编号、附件、上一张或聊天记忆，保证可单独复制到其他图像生成系统。默认 9:16，像素尺寸采用平台默认或自动设置；不自动追加8K、超高清等标签。用户明确要求尺寸时，按平台支持能力单列参数。默认不直接生图。

## 调用示例

- `$yumao-photography 卡提希娅，真人COS，收束，全身回头抓拍`
- `$yumao-photography 明确成年原创女性，开羽，漫展互动，n=3`
- `$yumao-photography 清宵，垂羽，窗边全身，羽色和饰件自动适配`
- `$yumao-photography 秧秧·玄翎，环覆，行走回头，ratio=4:5`（显式覆盖默认比例）

四形态的构造唯一来源为 [form-family.md](form-family.md)：收束低角侧伸，开羽外侧增加张角，垂羽连续下落，环覆侧向后掠。共同遵守连续遮眼、无假眼形、适中尺度、多羽片与浅层叠覆。不能为了某种摄影风格自动放大或缩没羽饰。

配色饰件自动以服饰为主、场景为辅；也可明确指定材质、颜色、金线或玉饰。默认 centered 使用可辨认的中央连接；指定布局01–10时使用对应侧部结构锚点，并按 [侧源非对称布局](side-origin-layouts.md) 展开实际路径，不能只写编号。简洁服饰用精简小件；眼形框不允许。参考图分配结构/尺寸/服装用途，不能声称只输入文字时生成器已接收参考图。

## 一致性与数量

- adaptive：默认，同一造型结构稳定；换装先遵守主文件的角色服装锁定规则，再自动适配装饰，不授权衍生换装。
- strict：同方案固定；用户明确要求的形态切换或换装联动仅开放指定维度。
- free：探索未固定项，仍保持用户已指定 Form 和核心遮眼要求。

`六角色六套，覆盖四形态` → 共六条，先说明分配。

`六角色，每个角色四形态各一套` → 共二十四条。

`同人物同衣服，四形态各一条，strict` → 共四条，只变指定 Form；不把此请求判为冲突。

用户只说随机时不保证平均覆盖；要求四形态都出现时安排覆盖。每条独立展开结构、人物、服装和参数，不写“同上”。新对话要求沿用却无基线时需补充原图/描述；不能凭空保证一致。

技能修复会审核并修改规则；失败图诊断会先区分实眼、假眼与普通阴影。只完成文本检查时不声称视觉通过。
